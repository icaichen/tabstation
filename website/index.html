Architectural Masterclass

Crash-Safe SkyLight WindowServer ⌘Tab Override

Many users want to replace the macOS default ⌘Tab completely, but traditional utilities use dangerous hacks that can leave your system switcher permanently broken if the app terminates unexpectedly. AltDeck communicates directly with SkyLight WindowServer SPI via CGSSetSymbolicHotKeyEnabled, accompanied by POSIX signal handlers (SIGINT, SIGTERM, SIGHUP) that restore Apple's native switcher instantaneously upon termination or quit.

100% Fail-Safe Guarantee If AltDeck is closed, native ⌘Tab is restored before the next frame is drawn.

System Architecture

        

          Engineered for raw speed.
        

        

          AltDeck is crafted with obsessive discipline. No web frameworks, no bloated bundles, and zero compromises on battery life.
        

      


      

        

          
< 1ms

          
Synchronous Dismiss

          

            Key release orders out the HUD synchronously (~0.5ms) via WindowServer flush while AXUIElement & browser activation run off the main thread.
          

        


        

          
1.5 MB

          
Tiny App Bundle

          

            Zero Electron, zero Chromium runtime, zero bundled frameworks. Compiled directly to native machine code via Swift Package Manager.
          

        


        

          
0% CPU

          
On-Demand Architecture

          

            Driven by CGEventTap, background window cache refresh, and ScreenCaptureKit snapshots only when needed—never polling at 60fps in the background.
          

        


        

          
2-Tier

          
Retina Aspect Cache

          

            Separates thumbnail strip captures from full-resolution previews while strictly preserving each window’s real aspect ratio—zero black bars.
          

        


        

          
0 Telemetry

          
Private & Auditable

          

            Zero analytics SDKs, zero tracking beacons, zero auto-updaters phoning home. Read every line of Swift source yourself under MIT.
          

        


        

          
Liquid Glass

          
Native macOS Aesthetics

          

            Supports Apple NSGlassEffectView on macOS 26+, Clear Glass, and Solid matte surfaces with Light/Dark themes and continuous squircle geometry.

              macOS enforces strict TCC privacy boundaries:
              


              1. Accessibility observes your hold modifier via CGEventTap and raises specific app windows through Apple’s AXUIElement APIs.
              


              2. Screen Recording powers live ScreenCaptureKit window thumbnails and on-demand Picture-in-Picture streams (never recorded to disk or sent over the network).
              


              3. Automation (optional, for S) is prompted once when you press S to list open tabs in Chrome, Safari, Edge, Brave, or Arc. You can inspect or manage all three anytime inside Settings → General.
            

          

        


        

          
          

            

              AltDeck queries the AppleScript scripting dictionaries of running browsers via a dedicated high-performance service. It enumerates window IDs and tab titles without injecting code or modifying browser processes. When you select a tab in AltDeck, it activates the target browser window and brings that exact tab to the front.

Crucially, AltDeck registers POSIX signal handlers (SIGINT, SIGTERM, SIGHUP) and termination hooks that restore Apple’s native Command-Tab immediately if AltDeck is ever quit or terminated.
