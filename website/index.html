Architectural Masterclass

Crash-Safe SkyLight WindowServer ⌘Tab Override

Many users want to replace the macOS default ⌘Tab completely, but traditional utilities use dangerous hacks that can leave your system switcher permanently broken if the app terminates unexpectedly. TabStation communicates directly with SkyLight WindowServer SPI via CGSSetSymbolicHotKeyEnabled, accompanied by POSIX signal handlers (SIGINT, SIGTERM, SIGHUP) that restore Apple's native switcher instantaneously upon termination or quit.

100% Fail-Safe Guarantee If TabStation is closed, native ⌘Tab is restored before the next frame is drawn.

System Architecture

        

          Engineered for raw speed.
        

        

          TabStation is crafted with obsessive discipline. No web frameworks, no bloated bundles, and zero compromises on battery life.
        

      


      

        

          
0.04s

          
Instant Cold Start

          

            Compiled directly to machine code via SwiftPM. TabStation loads its entire window hierarchy and starts listening for chords in milliseconds.
          

        


        

          
28 MB

          
Featherweight Memory

          

            While Electron-based tools consume 400MB+ just to sit idle, TabStation runs on a modest ~28MB footprint, preserving your memory for Xcode and Docker.
          

        


        

          
0% CPU

          
Zero Idle Drain

          

            Event-driven architecture based on CGEventTap and ScreenCaptureKit actors. While you work, TabStation sleeps completely, causing zero battery drain.
          

        


        

          
4x

          
Concurrent Capture

          

            Thumbnails render up to 4 windows concurrently using Apple Silicon Metal pipelines, sized to the exact on-screen cell at 2x Retina resolution.
          

        


        

          
0 Sockets

          
Air-Gapped Privacy

          

            TabStation contains no network libraries, no analytics SDKs, and no automatic updaters phoning home. What happens on your Mac stays on your Mac.
          

        


        

          
100%

          
Apple HIG Compliant

          

            Conforms strictly to Apple Human Interface Guidelines: vibrant HUD materials, 22pt rounded corners, specular edge rims, and native spring physics.

              While AltTab is a pioneer in bringing the Windows-style switcher to macOS, TabStation was built from scratch in pure Swift with Apple’s modern ScreenCaptureKit framework. TabStation delivers capabilities unavailable in AltTab: deep browser tab switching across Chrome, Safari, Edge, and Arc; floating Picture-in-Picture with universal mouse event forwarding; Spacebar Quick Look previews; integrated keyboard tiling (1/2, 1/3, 2/3 ratios); and a lightweight ~28MB footprint that matches modern macOS design tokens.

              macOS enforces strict sandboxing:
              


              1. Accessibility Permission is required to observe your hold modifier via CGEventTap and to raise specific windows through Apple's AXUIElement APIs rather than just activating the application in front.
              


              2. Screen Recording Permission is required by macOS ScreenCaptureKit to generate live window thumbnails. Without Screen Recording, TabStation falls back to large app icons. TabStation never records your screen to disk and never transmits any data over the network.
            

          

        


        

          
          

            

              TabStation queries the AppleScript scripting dictionaries of running browsers via a dedicated high-performance service. It enumerates window IDs and tab titles without injecting code or modifying browser processes. When you select a tab in TabStation, it activates the target browser window and brings that exact tab to the front.
            

          

        


        

          
          

            

              Yes. Unlike fragile hacks, TabStation communicates with the SkyLight WindowServer via CGSSetSymbolicHotKeyEnabled. Crucially, TabStation registers POSIX signal handlers (SIGINT, SIGTERM, SIGHUP) and termination hooks that restore Apple’s native Command-Tab immediately if TabStation is ever quit or terminated.
            

          

        


        

          
          

            

              TabStation is compiled as a Universal 2 binary with full native support for Apple Silicon (M1, M2, M3, M4, and Pro/Max/Ultra variants) as well as Intel Macs running macOS 14 Sonoma, macOS 15 Sequoia, or later.
